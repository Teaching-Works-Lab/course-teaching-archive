### 课程简介

**课程基本定位**

本课程是智能制造工程专业的专业选修课，面向智能装备与制造系统中的计算机闭环控制问题。课程在自动控制、微机接口、Python科学计算和人工智能基础上，系统讲授计算机控制系统、采样与离散化、数据采集与数字PID、模糊控制、神经网络控制、智能优化与学习控制以及综合系统设计。课程强调“对象—采集—计算—决策—执行—反馈”的闭环结构，把智能算法放入采样周期、噪声、饱和、延迟、稳定性和安全约束中评价。

**核心学习结果**

学生能够分析采样、量化、延迟和离散化对闭环性能的影响；设计和评价数字PID；构建基本模糊控制器、神经网络辨识/控制和智能优化方案；使用Python或等价工具完成数值仿真；针对数控装备、机器人、温度/压力过程或制造单元提出包含传感、算法、执行、通信、异常与安全边界的计算机智能控制方案。

**主要教学方法**

采用“控制对象与指标—原理推导—算法流程—数值仿真—工程案例—结果评价”的教学方式。课堂可使用Python（NumPy、SciPy、Matplotlib、python-control或等价工具）演示采样、数字PID、模糊推理、神经网络辨识/控制和优化算法。培养方案规定48学时全部为理论学时，因此代码演示与仿真分析属于理论教学方法，不另行虚构实验、上机或项目式学时。

## 二、课程目标

| 课程总目标 | 课程子目标（参考学校定位、培养目标、毕业要求） | 达成方法 |
|---|---|---|
| 1.知识 | 1.1 掌握计算机控制系统组成、采样保持、量化、离散化和离散系统基本性能，理解采样周期与计算延迟影响。 | 通过连续/离散闭环、采样信号和装备控制结构对比建立系统认识。 |
| 1.知识 | 1.2 掌握过程通道、数据处理、数字滤波、数字PID及抗饱和等改进方法。 | 通过温度、速度和位置控制案例比较噪声、采样和PID参数影响。 |
| 1.知识 | 1.3 掌握专家控制、模糊集合、隶属函数、规则、推理与解模糊，理解Mamdani/T-S控制。 | 将工程经验转化为规则库并比较隶属函数和规则变化。 |
| 1.知识 | 1.4 理解BP/RBF等网络在系统辨识、补偿和控制中的基本结构及训练、泛化和误差。 | 以非线性对象数据拟合和神经网络辅助控制分析模型边界。 |
| 1.知识 | 1.5 理解遗传算法、粒子群、学习控制、自适应和强化学习控制的基本思想。 | 以PID参数优化和重复任务为案例比较人工整定与智能优化。 |
| 1.知识 | 1.6 掌握智能控制系统综合设计、实时性、网络、可靠性、抗干扰、故障安全和人机交互约束。 | 以机器人、伺服轴或温控装备完成需求—架构—算法—验证分析。 |
| 2.能力 | 2.1 能绘制控制系统结构并分析采样、延迟、量化和噪声对控制效果的影响。 | 采用多采样周期和扰动对比，以曲线和指标解释选择。 |
| 2.能力 | 2.2 能设计数字PID、完成参数整定与饱和/噪声处理，并评价超调、调节时间和误差。 | 通过阶跃、扰动和噪声案例训练整定与评价。 |
| 2.能力 | 2.3 能将工程经验转化为模糊变量、隶属函数和规则库，构建基本模糊控制器。 | 完成规则表、推理过程、响应曲线和方案解释。 |
| 2.能力 | 2.4 能利用采集数据建立基础神经网络模型并用于辨识、补偿或控制方案分析。 | 比较训练/验证误差和闭环性能，说明数据覆盖与过拟合。 |
| 2.能力 | 2.5 能构造控制参数优化问题，使用遗传算法、粒子群或等价方法搜索并比较性能。 | 固定基线和随机种子，形成目标函数、约束和收敛证据。 |
| 2.能力 | 2.6 能针对智能制造装备提出含传感、算法、执行、通信、异常和安全的控制系统方案。 | 提交系统框图、数据流、策略、参数、风险和验证计划。 |
| 3.素质 | 3.1 形成以闭环、指标和证据评价控制效果的工程意识。 | 同时检查输出、控制量、扰动、边界和失败场景。 |
| 3.素质 | 3.2 形成尊重采样数据、单位、时间和实验条件的严谨态度。 | 通过噪声、延迟、饱和和模型失配案例明确假设与范围。 |
| 3.素质 | 3.3 形成安全、可靠和可维护的控制系统设计意识。 | 综合方案强制设置限幅、超时、异常状态和安全降级。 |
| 3.素质 | 3.4 形成控制、计算机、AI、传感器和装备机理的多学科系统观。 | 通过数控、机器人和过程装备案例进行结构分解。 |
| 3.素质 | 3.5 形成可复现计算与技术表达习惯，对工具或AI辅助结果承担验证责任。 | 课程作业保留参数、数据、代码/公式和结果依据。 |
| 3.素质 | 3.6 形成持续学习意识，能判断新算法的适用条件、工程成本与局限。 | 通过教材和技术资料阅读，以证据说明技术选择。 |
