二、课程目标

| **课程总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| --- | --- | --- |
| **1.知识** | 1.1 了解课程知识体系、课程定位及与后续课程的衔接关系，掌握本课程的学习要求、考核方式和基本规范，建立对智能制造专业学习路径的整体认知。 | 用专业培养链条和课程地图展示课程在培养体系中的位置，讲清课程目标、学习要求和考核方式，帮助学生建立对课程与专业发展的整体认识。 |
| 1.2 理解智能制造的产生背景、发展阶段、基本概念和核心特征，能够从制造业转型升级的角度把握智能制造发展的现实需求。 | 通过制造业发展历程、典型案例和概念辨析，系统讲授智能制造的背景、内涵与特征，帮助学生形成清晰的概念框架。 |
| 1.3 理解信息物理系统（CPS）的基本概念及设备层、控制层、车间层、企业层、协同层之间的关系，掌握智能制造系统的基本组成。 | 借助系统结构图、层级模型和典型场景分析，讲清物理系统、信息系统和控制系统的耦合关系，强化学生对系统组成的整体认知。 |
| 1.4 了解RAMI4.0、IIRA、IMSA等典型参考模型的基本结构与差异，理解智能制造系统架构在系统建设、标准化和集成应用中的作用。 | 通过架构对比、模型讲解和实例分析，引导学生把握不同参考模型的逻辑框架与适用场景，建立架构化认知。 |
| 1.5 了解物联网、大数据、云计算、人工智能、工业机器人、增材制造等关键技术在智能制造中的作用与相互支撑关系。 | 围绕关键技术链条开展模块化讲授，结合典型设备、平台和应用案例，帮助学生理解技术体系的协同作用。 |
| 1.6 了解离散型智能制造、流程型智能制造、网络协同制造、远程运维、个性化定制、信息安全与产业发展趋势等内容，形成对专业方向的全景式认识。 | 通过典型制造模式、行业案例和发展趋势梳理，引导学生认识智能制造的主要应用场景、风险挑战与未来方向。 |
