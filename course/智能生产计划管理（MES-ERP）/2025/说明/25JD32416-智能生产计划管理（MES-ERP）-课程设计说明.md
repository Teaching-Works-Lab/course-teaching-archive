# 《智能生产计划管理（MES/ERP）》课程设计说明

培养方案硬数据：课程代码25JD32416，专业选修课，2学分，第7学期，总学时32，理论32，实验/上机/项目式均为0，考核方式考查。授课单位源数据为“机械学院”，学校大纲按正式学院名称写为“机械与动力工程学院”。

培养方案矩阵明确支撑6.1、6.2、6.3、8.1、8.2、10.1、10.2、11.1、11.2、12.1、12.2。因此课程不仅讲MES/ERP功能，还突出企业责任、职业规范、生产数据诚信、技术沟通、项目管理与经济决策。

课程主线：制造运营与ERP/MES体系 → MPS/MRP → 能力计划与排程 → 车间作业控制 → MES与ERP-MES集成 → APS/KPI/成本与持续改进。

培养方案没有设置上机和实验学时，因此大纲不虚构软件操作课；课堂可用Excel、Python或演示型MES/ERP界面辅助案例分析，但这些只是教学工具。
