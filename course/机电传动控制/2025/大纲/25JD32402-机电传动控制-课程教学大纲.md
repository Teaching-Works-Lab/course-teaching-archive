| **课程简介** | **课程基本定位**  本课程是智能制造工程、机械工程、机械工程（专升本）专业的一门重要的专业选修课，主要研究机电传动系统动力学规律，以及各类驱动电机的工作特性、运行控制与电气逻辑控制规律，为机电设备、自动化系统与智能制造装备的驱动设计、选型校核与控制优化奠定必要的机电基础。同时本课程又具有很强的工程应用性，能够直接应用于工业机械设备动力匹配、电机启停调速制动控制、低压电气回路设计与设备工况分析，是一门理论与实践结合比较紧密的课程。  **核心学习结果**  通过本课程的学习，学生能够掌握机电传动动力学、交直流电机与控制电机、低压电气控制的理论基础，初步具备综合应用所学机电知识分析、解决工业传动与电气控制实际问题的能力，对常见机电设备传动系统、电机拖动回路、电气控制线路进行原理分析、参数计算与方案设计的基本理论和方法。通过在教学过程中贯彻素质教育，学生能够具备坚持不懈的学习精神、严谨治学的科学态度和积极向上的价值观，为未来的专业学习、工程工作和生活奠定良好的基础。  **主要教学方法**  理论课堂主要采用讲授法学习新知识和例题；布置课上和课后练习，巩固所学新知识；重难点利用分组讨论法和互动提问加深理解。 | | | | | | |

二、课程目标

| **课程总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| --- | --- | --- |
| **1.知识** | 1.1了解本课程的知识体系以及与其他课程关系，理解本课程在专业学习中的作用；掌握课程学习要求，熟知成绩评定规则与课堂规范，明确学习方向，为系统学习机电传动系统与电动机知识奠定思想意识根基。 | 课程学习过程中，通过自主梳理、手绘思维导图的方式系统拆解本课程完整知识体系，清晰划分机电传动动力学基础、交直流驱动电机、精密控制电机、低压电气控制四大核心模块，理清各章节知识点的递进关系、并列关系与支撑关系，直观建立模块化、系统化的整体知识框架。 |
| 1.2掌握机电传动系统基本概念，包括机电传动系统组成、运动状态、转矩、转动惯量、负载特性；熟悉常见的机械传动机构类型以及对应的动力学特性，包括带传动、齿轮传动、多级轴系传动；掌握机电传动系统动力学等效折算方法，熟悉机电系统受力与运动分析、绘制传动系统力学模型的步骤。 | 通过课堂理论学习、知识点归纳梳理与例题训练，系统识记机电传动系统核心基本概念，精准理解转矩、转动惯量、负载特性等关键参数的物理意义。结合工程传动机构实物案例与原理图分析，对比掌握带传动、齿轮传动、多级轴系传动的结构特点与动力学性能差异，厘清不同传动机构的适用工况。 |
| 1.3掌握直流电动机基本概念，包括直流电动机结构组成、励磁方式、电动势与电磁转矩；熟悉直流电动机的运行特性以及对应的工作规律，包括固有机械特性、人为机械特性；掌握直流电动机启动、调速和制动的基本原理，熟悉直流电机工况分析、参数计算与特性曲线绘制的步骤。 | 通过课堂理论讲授、知识点梳理归纳和典型例题练习，系统掌握直流电动机的基本结构、不同励磁方式特点，深入理解感应电动势与电磁转矩的产生原理及物理意义。结合电机特性曲线图解分析、课堂案例对比学习，熟练掌握直流电动机固有机械特性和人为机械特性的变化规律、特征参数及适用工况。通过课后习题训练、工况仿真分析与曲线绘制实操，熟练掌握直流电动机启动、调速、制动各类控制方式的工作原理与操作特点。 |
| 1.4掌握三相异步电动机基本概念，包括三相异步电动机结构组成、旋转磁场、转差率与电磁转矩；熟悉三相异步电动机的运行特性以及对应的工作规律，包括固有机械特性、人为机械特性；掌握三相异步电动机调速和制动的基本原理，熟悉异步电机工况分析、参数计算与特性分析的步骤。 | 通过课堂理论讲授、知识点归纳梳理与原理推演学习，系统掌握三相异步电动机结构组成、旋转磁场产生条件，深刻理解转差率、电磁转矩等核心参数的物理意义及相互关联。结合工程实例与特性曲线对比分析，熟练掌握三相异步电动机固有机械特性和人为机械特性的变化规律、特征特点与适用场景。通过课堂典型例题演练、课后习题巩固与工况分析训练，熟练掌握异步电动机各类调速、制动方式的工作原理与运行特点。 |
| 1.5掌握控制电机基本概念，包括步进电动机、伺服电动机、测速发电机的结构组成与工作原理；熟悉各类控制电机的运行特性以及对应的性能规律，包括响应特性、定位精度与调速特性；掌握控制电机的基本控制方式与适用场景，熟悉自动化设备中控制电机选型、工况分析的基本步骤。 | 通过课堂理论讲授、知识点分类梳理与对比归纳学习，系统掌握步进电机、伺服电机、测速发电机的结构组成与核心工作原理，明确各类控制电机的功能定位与性能差异。结合自动化设备、数控进给、机器人关节等工程案例，对比分析各类控制电机的响应特性、定位精度与运行规律，厘清不同控制电机的适用工况与优缺点。通过课堂案例分析、课后知识点总结与选型练习，熟练掌握控制电机的基本控制方式与工作特性。 |
| 1.6掌握低压电器基本概念，包括接触器、继电器、熔断器、行程开关、控制按钮的结构组成与工作原理；熟悉常用低压电器的功能特性、选型原则与使用场景；掌握继电器-接触器基本控制线路的工作原理，熟悉电气原理图识图、线路分析与简单控制回路设计的步骤。 | 通过课堂理论讲授、电器实物认知与知识点归纳梳理，系统掌握各类常用低压电器的结构组成、工作原理与功能特点，明确不同电器的选型依据与适用工况。结合标准电气图纸案例解析、课堂逻辑推演学习，熟练掌握电气原理图绘制规范、识图方法与线路逻辑分析思路，厘清电机启停、正反转、联锁限位等典型控制线路的动作流程与保护原理。通过课堂线路分析训练、课后识图绘图练习与控制案例实操总结，熟练掌握基础电气控制回路的分析方法与设计流程，规范完成电气线路识图、逻辑校核与简易线路设计，全面夯实工业基础电气控制的理论功底与工程实践能力。 |

| 2.3 能够准确识别直流电动机各类励磁方式的结构特征与工作属性，正确辨析电机感应电动势、电磁转矩的产生机理与运行特性规律；能够熟练运用直流电机特性分析与参数计算的基本步骤，独立、规范地完成他励直流电动机固有与人为机械特性研判、曲线绘制及启停、调速、制动全工况解析，为后续机电传动系统动力匹配、电机选型与控制方案设计奠定坚实基础。 | 系统梳理直流电动机不同励磁方式的结构特征与工作属性，结合原理动画、特性曲线图谱与典型电机工况案例，精讲辨析各类励磁电机的电磁机理、电动势与电磁转矩的变化规律，引导学生精准识别、准确研判直流电机的运行特性差异。依托标准化解题流程开展课堂分步推演、例题实操训练，严格按照参数梳理、特性辨析、工况判定、曲线绘制的规范步骤，引导学生独立完成直流电机固有与人为机械特性分析、曲线图绘制以及启停、调速、制动各类工况的完整解析训练。 |
| 2.4能够准确识别三相异步电动机不同结构形式与运行磁场特性，正确判别电机转差率、电磁转矩的变化规律与机械特性；能够熟练运用异步电机参数计算与工况分析基本步骤，独立、规范地完成三相异步电动机固有与人为机械特性辨析、工况研判及调速制动方案解析，为后续工业传动设备电机选型与系统控制设计奠定坚实基础。 | 系统梳理三相异步电动机的结构形式、旋转磁场运行特性与核心工作参数，通过电机结构拆解、原理推演与工业工况案例精讲，引导学生精准辨析转差率、电磁转矩的变化规律，熟练判别异步电机固有与人为机械特性的特征差异与运行性质。依托课堂分步推演、典型例题实操训练，标准化拆解异步电机参数计算、特性辨析、工况研判、调速制动方案分析的完整流程，引导学生严格按照参数核算、特性对比、负载匹配、方案优选的规范步骤开展实操训练，独立完成不同工况下三相异步电动机运行状态解析与控制方案校核。 |
