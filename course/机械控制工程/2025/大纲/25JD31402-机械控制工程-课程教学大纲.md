二、课程目标

| **课程总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| --- | --- | --- |
| **1.知识** | 1.1了解本课程的知识体系以及与其他课程关系，理解本课程在专业学习中的作用；掌握课程学习要求，熟知成绩评定规则与课堂规范，明确学习方向，为系统学习静力学与材料力学知识奠定思想意识根基。 | 用思维导图展示核心模块逻辑关系，对比课程衔接，明确课程知识体系；解读课程学习要求，强化规范意识。 |
| 1.2掌握控制系统的基本概念，包括开环控制与闭环控制、输入与输出、反馈、偏差、稳定性、快速性、准确性等核心术语，能够准确区分不同控制系统的结构特点与工作原理。 | 采用讲授、案例演示与对比分析相结合的方式，结合机械工程实际控制系统实例，系统讲解开环 / 闭环、输入 / 输出、反馈等核心概念；通过课堂提问、小组讨论与典型结构辨析，强化对控制系统结构与工作原理的理解。 |
| 1.3熟悉比例、积分、微分、惯性、振荡等典型环节的数学模型、传递函数表达形式、动态响应特性与频率特性，能够识别各环节在系统中的作用与影响规律。 | 通过公式推导、图形演示与响应曲线对比，讲授典型环节的数学模型与传递函数；结合典型机械系统环节拆解练习，让学生识别环节类型、分析动态特性与频率特性，掌握各环节对系统的影响规律。 |
| 1.4掌握机械控制系统的数学建模方法，能够根据机械结构与物理定律建立微分方程，熟练运用拉普拉斯变换完成微分方程到传递函数的转化，正确推导简单机械系统的传递函数。 | 以机械传动、执行机构等实例为载体，讲授基于物理定律的微分方程建立方法；强化拉普拉斯变换训练与传递函数推导练习，采用 “示范 — 模仿 — 独立完成” 流程，训练学生机械系统建模能力。 |
| 1.5理解经典控制理论的核心分析方法，包括时域分析法、根轨迹分析法与频域分析法的基本原理、适用条件与分析步骤，掌握离散系统的基本概念、描述方法与分析基础。 | 分模块讲授时域、根轨迹、频域分析的原理与步骤，配合例题、仿真演示与绘图练习，让学生掌握分析流程；补充离散系统基础概念，通过对比连续系统，帮助学生理解描述方法与分析思路。 |
| 1.6掌握 PID 控制算法的基本原理、结构组成与各环节作用，理解比例、积分、微分参数对系统性能的影响规律，掌握常用 PID 参数整定方法，了解控制系统校正的目的、类型与基本设计思路。 | 结合工程应用案例讲解 PID 控制原理与各环节作用，通过仿真演示参数变化对系统性能的影响；讲授经验整定法等常用参数整定方法，介绍校正类型与设计思路，配合练习加深理解与应用。 |

| **2.能力** | 2.1能对常见简单机械系统（传动机构、执行部件、弹簧 - 质量系统等）进行结构拆解与工作原理分析，明确系统控制需求与性能要求，独立完成物理抽象与简化，建立合理的微分方程数学模型并准确推导系统传递函数。 | 通过典型机械系统实例拆解教学，引导学生掌握结构分析与物理抽象方法；开展分步建模训练，指导学生基于物理定律建立微分方程；通过课堂练习、课后作业与一对一纠错，强化传递函数推导能力，逐步实现独立建模。 |
| 2.2能熟练运用拉普拉斯变换、典型环节等效变换等方法，对机械控制系统进行框图化简与信号分析，完成系统结构整合与动态特性初步研判。 | 系统讲解拉普拉斯变换与框图化简规则，结合例题演示等效变换与信号流分析流程；组织专题练习与小组互评，让学生熟练掌握系统整合与动态特性初步判断方法，提升模型处理能力。 |
| 2.3能运用时域分析法、根轨迹法、频域分析法对控制系统进行全面分析，准确判断系统稳定性、快速性、准确性指标，对照工程标准判定系统性能是否满足设计要求。 | 分模块讲授时域、根轨迹、频域三大分析方法，结合工程性能指标标准开展案例训练；通过例题讲解、习题强化、仿真对比，让学生熟练判定稳定性、快速性、准确性，并形成规范化性能评估思路。 |
| 2.4能根据控制任务与性能指标，独立完成基础 PID 控制方案设计，合理选取结构形式与参数范围，形成完整的控制策略与实现流程。 | 结合机械控制工程实例讲解 PID 控制原理与方案设计流程；通过任务驱动式练习，指导学生根据性能指标选择 P/I/D 结构、确定参数范围，形成完整可执行的控制策略。 |
| 2.5能熟练使用 MATLAB/Simulink 等工具搭建仿真模型，开展控制系统仿真验证，通过实验平台完成 PID 参数调试与效果对比，形成可支撑设计结论的实验数据。 | 开展 MATLAB/Simulink 操作演示与上机实践，指导学生搭建仿真模型并开展验证实验；通过实验平台实操训练，强化参数调试、数据记录与结果对比能力，培养用实验数据支撑结论的工程素养。 |
| 2.6能识别并诊断控制系统常见故障与性能缺陷（如超调过大、稳态误差偏高、响应迟缓、稳定性不足），分析产生原因并提出可行的优化改进思路。 | 通过典型故障案例剖析与仿真对比演示，引导学生识别常见性能缺陷；组织问题诊断讨论课，指导学生从环节特性、参数设置、结构设计等角度分析原因，并提出校正、参数调整等优化思路。 |
