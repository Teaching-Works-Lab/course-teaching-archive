# 程序设计基础（C&C++）Ⅱ 教案源码包

本包与最终 Word 教案配套，包含：

- `程序设计基础_C_C++_II_教案_24次课_最终版.md`：完整 Markdown 教案；
- `images/lesson-01-knowledge-map.png` ~ `images/lesson-24-knowledge-map.png`：24 次课知识脉络图；
- `manifest.json`：课次—图片映射和文件校验信息。

## 使用约定

1. Markdown 中所有知识脉络图使用相对路径引用 `images/`。
2. 图片按课次稳定命名，避免依赖 Word 内部的 `image21.png` 等不稳定名称。
3. 修改 Word、Markdown 或知识图后，应同步更新其他交付物并重新执行一致性检查。
4. 本包不包含学校模板中无关的示例图片或隐藏素材。
