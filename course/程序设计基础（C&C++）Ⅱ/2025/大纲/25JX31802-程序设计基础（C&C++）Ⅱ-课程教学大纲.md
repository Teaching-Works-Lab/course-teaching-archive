### 课程简介

**课程基本定位**

本课程是《程序设计基础（C&C++）Ⅰ》的进阶课程，以 C++ 语言和面向对象程序设计为主要载体，在学生已经具备 C 语言结构化程序设计、数组、指针和函数基础的前提下，重点学习类与对象、构造与析构、继承与派生、多态、运算符重载、虚函数、模板、命名空间和异常处理等机制。课程承担从“能够编写过程式程序”向“能够进行面向对象建模与程序设计”的能力转换，为后续数据结构、嵌入式软件、人工智能应用以及复杂工程软件开发奠定程序设计基础。

**核心学习结果**

通过本课程的学习，学生能够理解面向对象程序设计的基本思想，能够根据问题对象及其关系设计类、对象和类层次结构，能够利用封装、继承和多态提高程序的可维护性与可扩展性；能够使用模板、命名空间和异常处理组织较为规范、健壮的 C++ 程序，并能够在开发环境中完成面向对象程序的编写、调试、测试和改进。

**主要教学方法**

课程采用“概念建模—代码实现—上机验证—重构比较—综合设计”的教学方法。以教材案例和课堂练习建立面向对象概念，通过类设计、继承关系、多态行为和模板程序的连续上机训练强化理解；组织 C 与 C++ 实现对比、对象生命周期跟踪、类层次重构和异常场景测试，形成抽象建模、代码复用、接口设计和程序健壮性意识。

**大纲更新时间**：2025年9月
