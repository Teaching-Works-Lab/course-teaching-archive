# 《特种加工技术》教材与课程设计调研说明

培养方案硬数据：25JD32105，专业选修课，2学分，第7学期，32学时，其中理论26、实验6，考核方式为考查。培养方案矩阵支撑1.2、1.3、3.1、3.2、3.3、4.1、4.2、5.1、5.2、7.1、7.2、10.1、12.1、12.2。培养方案还将本课程与《增材制造技术》设置为第七学期专业选修二选一，因此本大纲主动避免重复增材制造内容。

课程主线：特种加工概论与方法选择 → 电火花成形/线切割 → 电化学加工 → 激光/超声/水射流 → 高能束/微细/复合加工 → 工艺设计、质量与可持续制造。

选用教材：白基成、刘晋春、郭永丰、杨晓冬等《特种加工（第7版）》，机械工业出版社，2022，ISBN 9787111679868。该书为本科国家级规划教材，系统覆盖电火花、电化学、激光、电子/离子束、超声、复合与微细加工，适合作为课程理论主线。
