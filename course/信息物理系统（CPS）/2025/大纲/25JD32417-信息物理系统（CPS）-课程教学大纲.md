### 课程简介

课程基本定位

本课程是智能制造工程专业的专业选修课，面向智能装备、智能产线和数字化工厂中的计算过程与物理过程深度融合问题，系统讲授信息物理系统（CPS）的基本概念、体系架构、离散计算模型、连续物理模型、混杂系统、组合建模、需求与模型验证以及系统设计方法。课程突出“计算—通信—控制—物理对象—反馈”闭环，并将CPS原理与数控装备、工业机器人、移动机器人、增材制造设备、智能产线和数字孪生等智能制造场景联系起来。



核心学习结果

学生能够解释CPS中计算、通信、控制与物理过程的耦合关系；使用状态机/自动机描述离散行为，使用常微分方程描述连续动态，建立简化混杂自动机和组合模型；区分安全性与活性需求，使用可达性、不变量和反例等基本思想分析模型；围绕智能装备或智能产线绘制CPS架构、定义状态与接口、分析时序和故障传播、提出安全约束，并形成结构化设计说明。



主要教学方法

课程采用“概念框架—数学/状态模型—执行轨迹—需求约束—案例验证—系统设计”的教学方式。课堂以状态图、时序图、方程、可达状态和系统架构图为主要表达载体，结合Python或仿真结果演示辅助理解，但不设置独立上机学时。教材案例用于解释通用原理，再迁移到工业机器人工作站、AGV物流、数控装备、3D打印设备和智能产线。

## 二、课程目标

| 课程总目标 | 课程子目标（参考学校定位、培养目标、毕业要求） | 达成方法 |
|---|---|---|
| 1.知识 | 1.1 理解CPS的概念、发展背景和基本特征，掌握计算、通信、控制与物理过程闭环耦合的基本架构，理解CPS与嵌入式系统、物联网、工业互联网和数字孪生的联系与区别。 | 通过CPS架构图、典型智能装备和智能产线案例进行概念辨析。 |
| 1.知识 | 1.2 掌握状态、事件、迁移、有限状态机和自动机等离散计算模型基本概念，理解输入输出、同步交互和执行轨迹。 | 通过设备启停、互锁、机器人任务和故障恢复案例讲授状态机。 |
| 1.知识 | 1.3 理解连续物理过程的状态变量、输入输出、常微分方程和基本动态特性，掌握从物理对象到连续模型的基本建模思路。 | 以电机、移动平台和温度过程为例建立简化连续模型。 |
| 1.知识 | 1.4 掌握混杂系统、混杂自动机、组合建模、需求与模型验证的基本概念，理解安全性、活性、可达性、不变量和反例。 | 通过温控、运动控制、安全互锁和多设备协同案例分析。 |
| 2.能力 | 2.1 能够从智能制造场景中识别物理对象、计算节点、传感器、执行器、通信链路、控制逻辑和反馈关系，绘制CPS系统架构图。 | 使用“对象—信号—状态—动作—反馈”模板完成架构分析。 |
| 2.能力 | 2.2 能够建立设备有限状态机，定义状态、事件、迁移、守卫条件和异常状态，并根据执行轨迹检查逻辑完整性。 | 通过设备、机器人和AGV任务状态模型开展建模与互评。 |
| 2.能力 | 2.3 能够依据简化假设建立连续模型和混杂模型，解释参数与接口的工程意义，分析模式切换、组合冲突和模型适用边界。 | 采用方程、混杂自动机图和组合状态分析完成建模任务。 |
| 2.能力 | 2.4 能够把工程需求转化为安全性、活性或时序约束，使用可达性、不变量、轨迹检查和反例分析开展基本验证，并完成智能装备或产线CPS概念设计。 | 综合任务提交架构图、状态模型、接口表、需求表、验证证据和设计说明。 |
| 3.素质 | 3.1 形成跨学科系统思维，能够从机械、电气、控制、计算机和网络多层关系理解智能制造系统。 | 通过跨域架构拆解和系统边界讨论训练整体分析。 |
| 3.素质 | 3.2 形成模型与证据意识，能够明确建模假设、参数来源和适用边界，避免把模型结果等同于真实系统。 | 所有模型任务记录假设、参数、验证方法和局限。 |
| 3.素质 | 3.3 形成安全可靠与接口规范意识，理解软件逻辑、网络时延、传感误差和执行故障对物理设备与人员安全的影响。 | 结合互锁失效、通信延迟和错误控制命令开展风险分析。 |
| 3.素质 | 3.4 形成可验证设计、持续改进和自主学习意识，能够辨析数字孪生、工业互联网、边缘计算和AI在CPS中的角色与局限。 | 通过反例、故障注入和近年技术案例形成“发现—修正—复验”闭环。 |
