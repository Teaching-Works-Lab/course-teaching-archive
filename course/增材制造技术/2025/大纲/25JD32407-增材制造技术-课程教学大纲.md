## 二、课程目标

| 课程总目标 | 课程子目标（参考学校定位、培养目标、毕业要求） | 达成方法 |
|---|---|---|
| 1.知识 | 1.1 理解增材制造的基本概念、发展脉络、标准化分类和完整工艺链，掌握增材制造相对于减材制造、等材制造的主要特点、优势与局限。 | 通过制造方式对比、标准分类图和典型产品案例，建立从数字模型到实体零件的总体认知框架。 |
|  | 1.2 掌握材料挤出、槽式光固化、粉末床熔融、粘结剂喷射、定向能量沉积和薄材叠层等主要工艺的成形原理、设备组成和适用场景。 | 采用工艺动画、设备结构图、样件对比和参数表，分析不同能量源、材料形态与逐层成形机制。 |
|  | 1.3 掌握聚合物、光敏树脂、金属粉末及复合材料等常用增材制造材料的基本特性，理解材料、工艺参数、组织性能和成形质量之间的关系。 | 通过材料数据、成形窗口和失效样件分析，建立材料选择、过程控制与零件性能之间的联系。 |
|  | 1.4 掌握增材制造数字前处理和面向增材制造设计的基本方法，包括模型格式、网格检查与修复、成形方向、支撑、切片、路径和G-code等内容。 | 结合真实零件模型开展“模型检查—方向比较—支撑设计—切片验证”全过程演示与练习。 |
|  | 1.5 掌握成形参数、典型缺陷、后处理和质量评价的基本知识，理解尺寸精度、表面质量、力学性能、缺陷控制和过程追溯的主要方法。 | 通过参数对照、缺陷图片与实验数据，分析翘曲、拉丝、欠挤出、层移、固化不足和支撑痕迹等问题。 |
|  | 1.6 了解增材制造在航空航天、医疗、汽车、模具和个性化产品中的应用，理解生产成本、安全环保、知识产权、开源装备和智能监测的发展趋势。 | 通过行业案例、成本与周期比较、开源设备结构和过程监测案例，讨论技术采用条件与工程责任。 |
| 2.能力 | 2.1 能够根据零件功能、材料、结构、精度、批量和成本要求，比较不同增材制造工艺并完成初步工艺与材料选择。 | 以多类零件为对象建立工艺决策表，训练需求分解、方案比较和选择依据表达。 |
|  | 2.2 能够使用切片及模型处理工具完成模型检查、修复、缩放、成形方向、支撑、分层和路径参数设置，并识别可制造性问题。 | 通过同一模型的多方案前处理练习，比较成形时间、材料消耗、支撑量和风险差异。 |
|  | 2.3 能够规范操作FDM设备，完成平台与喷嘴检查、材料装载、切片文件传输、打印监控和基本维护，并开展参数对比实验。 | 在实验中执行设备检查清单和操作规程，记录温度、速度、层高、填充、支撑及打印结果。 |
|  | 2.4 能够规范完成SLA成形准备、支撑与方向设置、树脂操作、打印、清洗和二次固化，并识别光敏树脂相关安全风险。 | 通过SLA全流程实验和个人操作核验，训练防护、设备操作、后处理和废液处置能力。 |
|  | 2.5 能够依据过程记录、尺寸测量、外观和典型缺陷分析增材制造质量问题，定位可能的材料、设备、参数或后处理原因并提出改进方案。 | 采用缺陷样件、实验数据和故障树开展“现象—证据—原因—验证—改进”闭环分析。 |
|  | 2.6 能够围绕具体产品完成增材制造应用方案，形成包含工艺选择、模型与支撑、材料参数、设备操作、质量验证、成本安全和交付文件的技术报告。 | 以综合项目组织需求分析、方案评审、样件或数字验证、结果汇报和个人答辩。 |
| 3.素质 | 3.1 树立设备、激光、粉末、热端和光敏树脂操作中的安全底线与规范意识，能够遵守实验室和工艺操作要求。 | 将个人防护、设备检查、异常停机、材料存储和废弃物处置纳入实验全过程评价。 |
|  | 3.2 形成基于真实数据、过程记录和可重复验证评价成形质量的科学态度，避免只展示成功结果或随意修改数据。 | 要求实验提交原始配置、过程照片、测量结果、失败样件和参数变更记录。 |
|  | 3.3 形成材料节约、能耗控制、可回收利用和全生命周期意识，能够分析增材制造的资源优势及其环境代价。 | 对比支撑用量、打印时间、材料损耗和后处理资源消耗，将可持续性纳入方案评价。 |
|  | 3.4 形成主动学习和创新意识，能够跟踪新材料、新工艺、开源软硬件和智能监测技术，并判断其适用边界。 | 设置前沿资料阅读和开源系统分析任务，要求说明技术收益、风险、验证条件和迁移路径。 |
|  | 3.5 形成团队协作和工程沟通能力，能够使用模型、切片截图、工艺卡、数据表和技术报告清晰说明个人工作与团队方案。 | 综合项目采用明确分工、阶段评审、版本记录、成果汇报和个人问答。 |
|  | 3.6 形成精益求精的质量责任和工匠精神，能够规范完成模型、参数、操作、后处理、检测和文件交付。 | 以可制造性、操作规范、样件质量、记录完整性和复盘改进作为持续评价要点。 |
