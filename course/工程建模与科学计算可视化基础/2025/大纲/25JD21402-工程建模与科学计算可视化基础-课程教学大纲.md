二、课程目标

| **课程总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| --- | --- | --- |
| **1.知识** | 1.1 了解本课程的知识体系以及与其他课程关系，理解本课程在专业学习中的作用；掌握课程学习要求，熟知成绩评定规则与课堂规范，明确学习方向，为系统学习工程建模与科学计算可视化知识奠定思想意识根基。 | 用思维导图展示核心模块逻辑关系，对比课程衔接，明确课程知识体系；解读课程学习要求，强化规范意识。 |
| 1.2 掌握Python编程语言的基础知识，包括基本数据类型、控制结构、函数与模块等；熟悉Python在工程计算中的应用特点。 | 系统讲授Python基础知识，结合工程实例辨析各类数据类型和结构特性；布置Python编程专项训练，强化编程能力，确保学生牢固掌握Python编程基础。 |
| 1.3 全面深入掌握NumPy数组操作与数值计算基本方法。对于数组操作，了解创建数组的方式，如用不同函数生成特定数组；熟悉索引、切片操作，能灵活提取数据。数值计算方面，掌握加、减、乘、除等基本运算在数组上的实现，以及矩阵运算等复杂计算。理解向量化计算优势，它能提高效率、减少执行时间且使代码简洁易读。此外，熟悉NumPy在数据分析、机器学习、物理学模拟等科学计算领域的应用场景与操作方法。 | 通过严谨的推导，使学生理解NumPy数组操作和数值计算的基本原理；分析NumPy在工程计算中的典型应用，总结归纳常用函数和方法；通过分析工程实例，引导学生理解NumPy在工程问题中的实际应用。 |
| 1.4 全面掌握Pandas数据处理的各类基本方法，具体涵盖数据的导入操作，比如从各种不同格式的文件（如CSV、Excel等）中导入数据；数据的清洗工作，像处理缺失值、去除重复数据等；数据的转换过程，例如对数据进行类型转换、重新编码等；以及数据的聚合操作，像分组求和、求平均值等。同时，要十分熟悉Pandas在工程数据分析领域的实际应用，能够运用Pandas来对工程数据进行有效的分析和挖掘，从而为工程决策提供有力的支持。 | 系统讲授Pandas数据处理方法，结合工程数据实例分析数据清洗和转换的技巧；布置Pandas数据处理专项训练，强化数据处理能力，确保学生牢固掌握Pandas应用。 |
| 1.5 初步掌握Matplotlib等常见数据可视化的基本方法，这里所涵盖的内容丰富多样，具体包括各类不同图表的精准绘制，像柱状图、折线图、散点图等常见图表的绘制技巧，同时还包括对这些图表样式的细致设置，比如颜色的搭配、线条的粗细、标记的样式等；深刻理解数据可视化在工程分析领域所具有的重要性，明白其对于清晰呈现数据特征、辅助决策等方面的关键作用。 | 通过实例演示，使学生掌握Matplotlib基本绘图方法；分析工程数据可视化案例，引导学生理解可视化在工程问题分析中的价值；布置可视化专项训练，强化学生图表设计能力。 |
| 1.6 在学习过程中，要初步且扎实地掌握常见 Python 集成开发环境（IDE）的具体使用方法。这里所说的常见 Python 集成开发环境，涵盖了诸如 PyCharm、Visual Studio Code 等在编程领域广泛应用的工具。不仅要熟悉这些开发环境的基本操作界面，还要深入了解其各项功能，例如代码编辑、调试、运行等功能的具体操作流程。同时，要具备人工智能辅助编程和项目开发的能力，这包括学会利用像 Copilot 等人工智能编程辅助工具来提高编程效率，以及运用人工智能技术为项目开发提供思路和解决方案，从而在实际的编程和项目开发中能够更加高效、准确地完成任务。 | 系统讲解PyCharm与Visual Studio Code的核心功能模块（界面布局、代码编辑、调试工具、版本控制），通过对比演示两种IDE的操作差异；设计阶梯式实操任务（环境配置→代码调试→项目管理），要求学生完成从单文件脚本到多模块项目的开发流程；引入AI辅助工具的使用教学，通过案例演示如何利用AI生成代码片段、优化算法逻辑及解决调试问题；布置"AI辅助项目开发"专项作业，要求学生记录AI工具的使用场景与效率提升数据，撰写技术反思报告。 |

| **课程**  **总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| **2.能力** | 2.1 具备熟练且精准地运用工程问题建模基本方法的能力，能够深入剖析实际工程问题中的各种要素和关系，凭借扎实的专业知识和丰富的实践经验，把复杂多样的实际工程问题逐步进行抽象和提炼，最终将其准确无误地转化为对应的数学模型。 | 通过对具体且具有代表性的工程案例进行深入分析，详细且系统地讲授工程建模所涉及的基本步骤，包括如何进行问题的界定、数据的收集与整理、模型的选择与构建等；精心布置具有一定针对性和挑战性的工程问题建模任务，运用多样化的引导方式，逐步引导学生将错综复杂的实际问题进行拆解和分析，进而准确地转化为数学模型，帮助学生掌握从实际到理论的转化思维和方法。 |
| 2.2 在实际的工程工作场景中，具备十分熟练地运用NumPy和Pandas这两个强大工具来开展有关工程数据的计算与分析工作的能力。NumPy提供了高效的多维数组对象以及对数组进行各种操作的函数，利用这些功能可以方便快捷地处理大规模的工程数据；而Pandas则擅长数据的读取、清洗、转换等操作，能够将杂乱无章的工程数据整理成便于分析的格式。与此同时，还具备运用Scipy进行公式计算与分析的能力。Scipy拥有丰富的科学计算库，涵盖了数值积分、优化、插值等多个领域，能够针对复杂的工程公式进行精确的计算和深入的分析。 | 通过工程数据计算案例，讲授科学计算方法；布置工程数据处理任务，强化学生数据计算能力。通过讲解NumPy多维数组操作、Pandas数据清洗转换等核心功能，结合工程数据计算案例，引导学生掌握数据计算与分析方法；布置包含大规模工程数据的综合处理任务，强化运用NumPy、Pandas进行数据清洗、转换及Scipy进行公式计算的实践能力，培养工程数据科学处理思维。 |
| 2.3 在相关技能方面，具备能够极为熟练地运用 Matplotlib、PyVista 等专业工具的能力。通过经历系统且全面的训练过程，深入掌握了这些工具的具体应用方法。凭借所掌握的技能，可独立自主地完成工程数据的多维度可视化分析工作。在分析过程中，能够从多个不同的维度对工程数据进行细致的剖析和处理。并且，还可以结合科学计算所得到的结果，精准地呈现出其中的关键现象以及内在的规律，为进一步的研究和决策提供有力的支持。 | 首先深入解析Matplotlib基于面向对象的核心架构，涵盖折线图、热力图及速度场矢量图（Quiver Plot）的参数配置与数据映射机制；继而剖析PyVista基于VTK的渲染管线，重点讲解网格数据结构（Unstructured Grid）的处理流程、光照模型设置及三维交互原理。课程将以简单的工程实战案例，演示如何利用Matplotlib绘制二维速度场矢量分布以捕捉局部流动特征，并结合PyVista构建流场三维动态模型，通过流线追踪与等值面渲染直观呈现漩涡形成与演化的时空过程。在此基础上，引导学员开展“从二维数据分布到三维结构展示”的阶梯式实践训练，独立完成从原始数据清洗、多维度图表设计到最终结果解读的全流程，从而全面培养解决复杂工程问题的数据可视化综合应用能力。 |
| 2.4 具备在短时间内快速学习新知识、新技能，并积极尝试使用Python领域中新工具的能力。在面对实际的工作场景时，能够迅速掌握新工具的使用方法和特点，将其融入到日常的开发工作当中。同时，还能够依据具体的工程需求，主动去探索Python生态系统里种类丰富的扩展库，像Streamlit、MicroPython等这些具有代表性的扩展库。不仅要了解它们的基本功能，还需要深入研究如何将这些扩展库应用到实际的工程项目中，以实现项目的预期目标。此外，要充分理解开源工具在应对和解决复杂工程问题时所具有的独特价值。开源工具往往汇聚了众多开发者的智慧和经验，通过合理地运用这些工具，可以提高开发效率、降低开发成本，为解决复杂工程问题提供更加有效的途径和方法。 | 通过系统讲解Python生态中快速学习新工具的方法论及开源工具在解决复杂工程问题中的核心价值，举例演示如何依据具体工程需求主动探索并应用Streamlit构建交互式数据看板、利用MicroPython实现嵌入式控制等代表性场景；进而引导学员在面对实际工作场景时，开展从工具特性调研、快速上手实践到融入日常开发流程的阶梯式训练，使其能够迅速掌握新工具的使用方法并将其灵活应用于项目目标达成，最终培养出具备短时间内快速掌握新知识新技能、主动探索Python丰富扩展库以及高效运用开源工具解决复杂工程问题的综合应用能力。 |
| 2.5 具备集成先进的AI工具以进行辅助开发与交互学习的显著能力。在实际工作场景中，不仅能够熟练地运用像VSCode这样功能强大的代码编辑工具，还能借助通义千问这类先进的AI大模型工具来开展代码辅助开发工作。在运用这些工具的过程中，采用边用边学、快速迭代的有效方式，不断积累经验、优化方法，进而高效地解决在开发过程中遇到的各种实际问题。通过这样一系列的实践操作，逐步深入掌握交互式学习与开发的科学方法，以更好地适应不断变化的开发需求和技术环境。 | 讲解集成先进AI工具进行辅助开发与交互学习的核心方法论，重点剖析VSCode等智能编辑器与通义千问等大模型工具的协同工作机制及“边用边学、快速迭代”的高效开发策略；举例演示在实际编码场景中如何利用AI大模型进行代码自动生成、错误调试及逻辑优化，展示如何通过人机协作高效解决复杂开发难题；进而引导学员开展从工具配置、场景化应用到持续经验积累的阶梯式实践训练，使其熟练掌握交互式学习与开发的科学方法，最终培养出能够灵活集成先进AI工具以适应动态技术环境、高效解决实际工程问题的综合应用能力。 |

| 3.5 强化精益求精的工匠精神与规范化工程习惯，在代码编写、文档撰写及报告呈现中追求逻辑严密、格式规范、界面美观，体现卓越工程师的职业素养。 | 推行PEP8代码规范标准，将代码缩进、命名规范、注释完整性纳入平时成绩考核，使用Lint工具自动检测代码质量；制定统一的《工程分析报告撰写模板》，对图表标题、单位标注、误差分析等细节提出严格量化要求；在期末答辩中设立“最佳工程实践奖”，表彰在代码重构、可视化美学及文档规范性方面表现突出的学生，树立高质量工程交付的标杆。 |

**（二）考核方式与评分标准**

期末考查采用2-3人小组项目形式，学生需在教师指导下完成工程建模与科学计算可视化项目（含问题定义、模型建立、程序实现、结果分析、可视化表达及总结反思），提交5000-8000字报告及源代码、数据等支撑材料，重点评价综合应用能力、团队协作与学术规范意识。

考核内容包含5部分：课程导论与工程建模思维、Python编程基础与计算逻辑、科学计算核心与数据处理、数据可视化设计与表达、综合建模与前沿工具应用。考核方式包括3种：平时表现、课程作业、期末考查，每一种均折合成百分制记录。最终成绩100%=平时表现20%＋课程作业20%＋期末考查60%。
