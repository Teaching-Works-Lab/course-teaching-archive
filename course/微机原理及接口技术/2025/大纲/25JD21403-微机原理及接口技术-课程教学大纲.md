二、课程目标

| **课程总目标** | **课程子目标（参考学校定位、培养目标、毕业要求）** | **达成方法** |
| --- | --- | --- |
| **1.知识** | 1.1 理解课程定位和知识主线，掌握微机系统、单片机系统及 80C51/MCS-51 单片机在智能制造、工业控制和仪器设备中的基础作用，建立课程整体认知框架。 | 通过课程导论、典型控制产品分析和培养方案定位说明，引导学生从「系统结构—程序设计—接口控制—仿真验证」的视角把握课程主线。 |
| 1.2 掌握 80C51 单片机的系统结构、引脚功能、最小系统、存储器组织、特殊功能寄存器、复位及时序等基础理论，理解硬件资源之间的协同关系。 | 结合结构图、最小系统原理图、寄存器表和故障案例开展分层讲解，使学生建立从引脚到模块、从模块到系统的结构化认知。 |
| 1.3 掌握汇编语言基础、寻址方式、常用指令及程序设计方法，理解底层程序与硬件端口、寄存器控制之间的对应关系。 | 通过指令分类讲授、程序阅读、程序纠错和仿真验证相结合的方式，帮助学生建立底层控制思维。 |
| 1.4 掌握 C51 语言的程序结构、基本语法、数据类型、函数与指针应用，理解 C51 程序调用单片机内部资源的基本方法。 | 采用「语法规则+典型例程+任务实现」的教学方式，通过端口控制、显示控制和按键控制等任务强化知识掌握。 |
| 1.5 掌握中断系统、定时/计数器和串行口的工作原理、控制寄存器、配置方法和典型应用，理解事件驱动、时间驱动和通信控制的程序设计思想。 | 以中断响应、定时显示、电子秒表和串口通信任务为载体，结合流程图、寄存器配置表和仿真现象进行讲解。 |
| 1.6 掌握 Keil 与 Proteus 联合开发、上机仿真和实验实施的基本流程，理解「电路搭建—程序编写—仿真验证—现象分析—实验总结」的闭环学习方式。 | 围绕 12 个上机任务和 4 个实验项目开展全过程训练，强化学生对程序开发、功能验证和实验分析的系统认识。 |
