# 《数据结构（C）》教材与编制依据

## 一、课程定位与语言说明

“数据结构（C）”中的“（C）”为培养方案版本标识，不表示C语言。本大纲统一使用Python讲授和实现数据结构与算法。

## 二、考核结构重写

按用户要求“二二四”并结合 Skill 总评权重必须合计100%的合同，本版采用：

- 平时成绩20%
- 课程作业20%
- 综合项目20%
- 期末闭卷考试40%

即三个20%过程/实践考核 + 40%期末闭卷考试。综合项目依托既有16学时上机递进形成，不新增项目式学时。
