# 《数据结构（C）》教材与Python实施路线说明

## 一、必须固定的课程解释

- 课程正式名称：数据结构（C）
- 课程代码：25JX21800
- “（C）”是培养方案中的课程版本标识（A/B/C中的C），不表示C语言。
- 课程以Python 3作为理论示例、上机实现、综合项目和代码考核的主要语言。
- 不设置C语言语法、指针或动态内存作为课程教学与考核要求。

## 二、培养方案硬信息

- 学科基础必修课；2.5学分；第5学期。
- 总学时40：理论24、上机16。
- 考核方式：考试。
- 授课学院使用学校正式全称“计算机与信息技术学院”。

## 四、教学实现原则

1. Python是课程主语言，但不能把数据结构课降格为Python容器调用课。
2. 顺序表、链表、栈、队列、树、堆、图、散列表和排序等核心操作先使用Python类、对象引用和基本序列自行实现。
3. `list`、`collections.deque`、`heapq`、`dict`、`set`和NetworkX用于对照、验证、性能比较和工程应用。
4. 所有任务包含正常、边界和异常测试，并使用`timeit`或等价方法开展多规模性能实验。
5. 智能制造应用案例用于解释结构选择，不额外引入与数据结构无关的大型平台或框架。

## 五、课程结构

- 数据结构、ADT与复杂度：3理论学时；
- 线性表、链表、栈与队列：4理论学时；
- 递归、字符串与状态空间搜索：4理论学时；
- 树、二叉树、堆与优先队列：5理论学时；
- 图结构与图算法：4理论学时；
- 查找、散列、排序与综合比较：4理论学时；
- 四个Python上机任务：各4学时，共16学时。

## 六、考核结构

最终成绩100%=平时表现15%＋上机任务25%＋Python算法综合项目10%＋期末考试50%。期末考试以数据结构原理、算法过程、复杂度和Python算法阅读/设计为主，不考C语言语法。
