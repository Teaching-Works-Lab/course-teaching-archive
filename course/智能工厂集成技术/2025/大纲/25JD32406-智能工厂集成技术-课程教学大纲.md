### 课程简介

**课程基本定位**

本课程是智能制造工程专业的专业选修课，面向设备、单元、产线、车间与企业信息系统之间的集成问题。课程以智能工厂总体架构为主线，系统讲授制造资源与信息流、工业网络与通信、控制层与设备层集成、MES/ERP/PLM/WMS等业务系统协同、工业互联网平台与数据集成、数字孪生及智能工厂运行管理。课程强调“设备互联—数据贯通—业务协同—模型一致—运行闭环”，使学生形成从单机自动化向系统集成和工厂级协同提升的整体认识。

**核心学习结果**

学生能够识别智能工厂设备层、控制层、执行层、运营层和企业层的主要对象与接口；理解OPC UA、Modbus TCP、PROFINET、MQTT等典型通信与数据交换机制；分析工业机器人、数控机床、PLC、视觉、物流等制造单元的集成关系；理解MES与ERP、PLM、WMS、QMS等系统之间的业务与数据协同；能够围绕智能制造场景形成系统架构、接口清单、数据流、信息模型、异常处理、安全与运维方案，并评价集成方案的可扩展性、互操作性和可维护性。

**主要教学方法**

课程采用“工厂场景—体系架构—接口与数据—典型系统—集成流程—案例评审”的教学方式。培养方案规定32学时全部为理论学时，因此PLC/机器人通信、MES、工业互联网平台、数字孪生等软件或案例演示均作为理论课堂教学方法，不另行虚构实验、上机或项目式学时。课堂通过系统框图、接口表、数据流图、时序图和典型智能工厂案例训练集成思维。

## 二、课程目标

| 课程总目标 | 课程子目标（参考学校定位、培养目标、毕业要求） | 达成方法 |
|---|---|---|
| 1.知识 | 1.1 理解智能工厂、智能制造系统、CPS与工业互联网的关系，掌握设备—单元—产线/车间—工厂的分层架构与集成对象。 | 通过典型智能工厂架构图和制造流程分析建立层次化系统认识。 |
| 1.知识 | 1.2 掌握工业以太网、现场总线和常用工业通信协议的基本原理，理解地址、周期、实时性、可靠性与网络拓扑。 | 比较PROFINET、Modbus TCP、OPC UA、MQTT等协议的适用层级与数据语义。 |
| 1.知识 | 1.3 掌握PLC、数控机床、工业机器人、机器视觉、AGV/AMR、传感器与边缘网关等制造资源的典型接口和集成方式。 | 通过机器人上下料、机床加工与物流协同案例分析设备状态、命令和互锁。 |
| 1.知识 | 1.4 理解MES及其与ERP、PLM、WMS、QMS、SCADA等系统的功能边界、主数据和业务协同关系。 | 通过订单—计划—工单—执行—质量—入库的数据链分析系统边界与接口。 |
| 1.知识 | 1.5 理解工业数据采集、信息模型、边缘计算、工业互联网平台、数字孪生与数据中台的基本作用。 | 通过设备数据接入、统一建模和数字孪生案例说明数据从现场到应用的流动。 |
| 1.知识 | 1.6 掌握智能工厂集成项目的需求、架构、接口、联调、测试、运行维护、安全和持续优化基本方法。 | 以工厂级集成案例完成从需求到验收的过程分解。 |
| 2.能力 | 2.1 能够根据制造场景绘制智能工厂分层架构并识别设备、控制、执行、运营和企业系统之间的接口。 | 使用系统框图、对象清单和责任边界完成场景建模。 |
| 2.能力 | 2.2 能够根据数据类型、实时性、可靠性和网络范围选择通信方案，并形成基本网络与协议配置思路。 | 通过设备通信需求表比较不同协议和网络方案。 |
| 2.能力 | 2.3 能够分析机器人、机床、PLC、视觉与物流单元的状态、命令、互锁和异常信息，形成单元集成接口表。 | 以典型柔性制造单元进行信号、状态机和异常流程分析。 |
| 2.能力 | 2.4 能够梳理MES与ERP/PLM/WMS/QMS等系统之间的主数据、业务事件和接口关系。 | 通过订单和工单生命周期绘制业务时序与数据流。 |
| 2.能力 | 2.5 能够设计基本的设备数据采集、边缘处理、信息建模和平台接入方案，并说明数据质量与追溯要求。 | 围绕OEE、能耗、质量或设备健康场景形成数据字典与数据流。 |
| 2.能力 | 2.6 能够针对智能工厂场景形成包含架构、接口、数据、联调、测试、安全与运维的完整集成方案。 | 通过综合案例评审训练需求—设计—验证—交付闭环。 |
| 3.素质 | 3.1 形成跨机械、电气、控制、计算机和管理系统的整体系统观。 | 通过多系统边界和依赖关系分析避免局部最优。 |
| 3.素质 | 3.2 形成接口规范、版本、数据一致性与可追溯意识。 | 所有案例要求明确接口字段、来源、单位、版本和责任方。 |
| 3.素质 | 3.3 形成安全、可靠、可维护和可扩展的集成工程意识。 | 分析失联、异常数据、设备故障和系统降级场景。 |
| 3.素质 | 3.4 形成以标准、文档和测试证据开展跨团队协作的职业习惯。 | 采用接口表、时序图、测试矩阵和变更记录表达设计。 |
| 3.素质 | 3.5 形成数据治理、网络安全和工业信息安全责任意识。 | 结合身份认证、权限、分区、日志与备份讨论系统风险。 |
| 3.素质 | 3.6 形成持续学习意识，能够判断新平台、新协议和数字孪生技术的适用条件与迁移成本。 | 通过教材与技术资料阅读比较不同技术路线。 |
