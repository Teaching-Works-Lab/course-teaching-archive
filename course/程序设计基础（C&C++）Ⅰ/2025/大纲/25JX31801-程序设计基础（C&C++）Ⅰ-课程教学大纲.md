### 课程简介

**课程基本定位**

本课程是智能制造工程专业程序设计能力培养的基础课程，面向第一次系统学习程序设计的学生，以 C 语言为主要载体，建立“问题分析—算法设计—代码实现—编译调试—结果验证”的基本程序设计过程。课程重点训练数据表达、流程控制、数组与结构、指针、函数和模块化程序设计，为后续《程序设计基础（C&C++）Ⅱ》《数据结构（C）》《微机原理及接口技术》等课程中的软件设计、数据处理和嵌入式程序开发奠定基础。

**核心学习结果**

通过本课程的学习，学生能够理解 C 语言程序的基本结构和执行过程，能够根据简单工程任务设计程序流程，选择恰当的数据组织方式，使用控制语句、数组、结构、指针和函数完成程序实现；能够在开发环境中完成代码编写、编译、运行和调试，分析常见语法错误、逻辑错误和运行错误，并形成规范编程、严谨验证和持续改进的基本工程习惯。

**主要教学方法**

课程以“讲授示范—课堂练习—上机实践—错误分析—任务复盘”为基本教学组织方式。知识讲解与上机操作同步进行，结合教材课堂练习、上机实验和在线 OJ 练习形成递进式训练；开发环境以 Visual Studio Code（VS Code）为主要示例，同时强调编译、运行、调试和程序验证方法的可迁移性。

**大纲更新时间**：2025年9月
