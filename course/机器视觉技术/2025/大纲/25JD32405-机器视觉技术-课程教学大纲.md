### 课程简介

**课程基本定位**

本课程是智能制造工程专业的一门专业选修课，面向工业检测、测量、定位、识别与视觉引导等典型任务。课程以Python为统一实现语言，以NumPy和OpenCV为核心工具，建立“成像条件—图像处理—特征与测量—识别判定—性能评价”的机器视觉工作链。

**核心学习结果**

学生能够分析相机、镜头、光源与成像参数，使用Python/OpenCV完成图像预处理、分割、形态学、轮廓与几何测量、模板与特征匹配，理解深度学习视觉基本流程，并针对零件、装配、输送或FDM 3D打印场景形成可复现的视觉方案，以测量误差、误检/漏检、精确率/召回率、速度和鲁棒性评价结果。

**主要教学方法**

采用“成像现象—算法原理—Python最小实现—OpenCV工程实现—参数对比—结果验证”的案例驱动方式。培养方案规定32学时均为理论学时，因此课堂代码演示和案例复现不虚构为独立上机学时。所有案例要求保留原始图像、参数、中间结果、评价指标和失败样例。

## 二、课程目标

| 课程总目标 | 课程子目标（参考学校定位、培养目标、毕业要求） | 达成方法 |
|---|---|---|
| 1.知识 | 1.1 理解机器视觉系统组成、相机/镜头/光源及视场、分辨率、景深、曝光等成像参数。 | 通过零件检测、装配检查和3D打印监测案例拆解成像—处理—判定链路。 |
| 1.知识 | 1.2 掌握数字图像、颜色空间、直方图、几何变换、噪声与滤波等基础。 | 使用Python、NumPy和OpenCV进行像素、颜色、直方图和几何变换对比。 |
| 1.知识 | 1.3 掌握阈值分割、边缘检测和数学形态学的基本原理与参数影响。 | 比较不同滤波、阈值、边缘和形态学组合及其失败工况。 |
| 1.知识 | 1.4 掌握轮廓、连通域、几何特征、尺度换算与机器视觉测量定位方法。 | 以零件尺寸、孔位和工件姿态案例由像素特征得到工程量。 |
| 1.知识 | 1.5 掌握模板匹配、角点与局部特征检测匹配的基本思想和适用条件。 | 通过目标定位案例比较模板方法与局部特征方法。 |
| 1.知识 | 1.6 理解分类、目标检测、缺陷检测与深度学习视觉基本流程及评价指标。 | 以预训练模型推理和小型缺陷数据评价比较传统视觉与学习型视觉。 |
| 2.能力 | 2.1 能够根据检测、测量、识别或引导任务分析成像需求并提出基本视觉系统方案。 | 从目标精度、速度和环境条件反推成像参数并评审。 |
| 2.能力 | 2.2 能够使用Python、NumPy和OpenCV构建可复现的预处理、分割与形态学流程。 | 保存参数、中间图和失败样例，并用第二组图像验证。 |
| 2.能力 | 2.3 能够提取轮廓与几何特征，完成计数、尺寸测量、位置/角度估计和误差分析。 | 围绕标准件、孔槽和打印件完成尺度换算、容差与重复性分析。 |
| 2.能力 | 2.4 能够使用模板或局部特征完成目标定位与匹配，并分析尺度、旋转、遮挡和光照影响。 | 通过受控变量实验比较匹配率和误检。 |
| 2.能力 | 2.5 能够调用经过验证的预训练视觉模型完成基本推理并计算精确率、召回率等指标。 | 使用小规模推理案例和混淆矩阵评价结果。 |
| 2.能力 | 2.6 能够针对智能制造场景形成完整视觉方案，以图像、代码、参数、指标和失败案例说明依据。 | 通过零件、装配、输送和FDM打印案例形成综合技术报告。 |
| 3.素质 | 3.1 形成成像、算法、环境和判定阈值协同的系统工程意识。 | 通过光照变化导致算法失效的案例进行系统复盘。 |
| 3.素质 | 3.2 形成原始数据、参数、代码版本和失败样例可追溯的工程规范。 | 要求保留原图、配置、代码版本和评价脚本。 |
| 3.素质 | 3.3 树立质量与安全责任意识，理解误检、漏检和错误测量/引导的工程风险。 | 讨论关键缺陷漏检和错误定位的复核与安全措施。 |
| 3.素质 | 3.4 形成基于误差、混淆矩阵、速度和鲁棒性评价算法的实证意识。 | 不以单张成功截图作为验收依据。 |
| 3.素质 | 3.5 形成规范的Python工程表达、图表与技术文档习惯。 | 通过代码审查、流程图和技术汇报训练。 |
| 3.素质 | 3.6 形成持续学习和工具边界意识，对开源代码、预训练模型和AI辅助结果独立核验。 | 通过官方文档、最小复现和结果复核训练。 |
